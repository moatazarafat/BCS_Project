# Border Control System

## Overview

Border Control System is a Python application that simulates the workflow of a border checkpoint. The system manages travelers, passports, visas, and security inspections while generating reports and handling random events.

## Features

- Traveler Management
- Passport Validation
- Visa Validation
- Wanted List Management
- Daily Reports
- Random Events
- File Handling
- Object-Oriented Programming (OOP)

## Technologies

- Python
- OOP
- File Handling
